v0.18.0 을 다시 읽어 찾은 것들입니다. **한글 문서를 가져오는 기능을 쓰신다면 올려 주세요** — 그중 하나는 올린 파일 하나로 서버를 멈출 수 있습니다.

## 보안

### 올린 파일이 스스로 말한 길이를 믿고 있었습니다

`.hwp` 는 OLE2 복합 파일이고, 그 안의 디렉터리가 스트림마다 길이를 64비트로 적어 둡니다. muni 는 **그 숫자를 그대로 믿고 메모리를 잡았습니다.**

2KB 짜리 `.hwp` 가 길이를 `2^62` 라고 적어 두면 한 바이트도 읽기 전에 `makeslice: cap out of range` 로 죽습니다. 조금 더 얌전한 거짓말은 그냥 기계를 다 씁니다. **워크스페이스 구성원이라면 누구나 가져오기로 닿을 수 있었습니다.**

스트림은 그것을 담은 파일보다 길 수 없고, 이제 그렇게 말합니다.

## 수정

### 진짜 한글 문서의 굵기·기울임이 엉뚱한 비트에서 읽혔습니다

글자 모양 레코드에서 속성 워드는 **46바이트째**에 있습니다 — `UINT16[7]` 글꼴 이름, 그 다음 **한 바이트짜리** 배열 네 개, 그리고 기준 크기. muni 는 그중 하나를 두 바이트로 세어 53바이트째에서 읽었고, 그것은 기준 크기의 한복판입니다. **진짜 `.hwp` 의 굵게·기울임·밑줄·취소선이 전부 우연히 정해지고 있었습니다.**

muni 자신이 만든 시험 파일도 같은 잘못된 상수를 썼기 때문에 시험이 이것을 잡을 수 없었습니다.

### HWPX 에서 글자와 요소의 순서가 사라졌습니다

`<hp:t>가나<hp:tab/>다라</hp:t>` 가 `"가나다라"` 로 나오고 탭은 사라졌습니다. 읽는 쪽이 한 요소의 글자를 전부 한 곳에 모으느라 **그것이 어디에 있었는지**를 버렸기 때문입니다.

### 마크다운 붙여넣기가 더 좋은 클립보드를 버렸습니다

워드나 브라우저에서 목록을 복사하면 클립보드에 서식 있는 것과 맨 글자, 둘 다 실립니다. 맨 글자는 마크다운처럼 보이므로 muni 가 그것을 읽었고, **HTML 이 지고 있던 색·글꼴·표·그림을 버리고** 이미 있던 서식을 되찾으려 했습니다. 이제 클립보드에 더 나은 것이 없을 때만 합니다.

### 그 밖에

- 표를 다시 세우는 일이 행 × 1024열 × 칸이었고 시간 제한이 없었습니다. 500행짜리 정상적인 표가 25억 번을 돌았습니다.
- **탭이 자리 계산을 어긋나게 했습니다.** 탭도 제어 표시처럼 여덟 자리를 차지하는데 하나로 세어서, 탭 뒤의 낱말이 전부 남의 서식을 입었습니다.
- 칸 안의 표가 문서에 두 번 들어갔습니다.
- **muni 가 내보낸 HTML 을 다시 읽으면 도형이 도형이 아니었습니다.** 언어를 적을 자리가 없었습니다.
- 아무도 쓰지 않는 그림까지 전부 압축을 풀었습니다.
- 깊게 중첩된 XML 이 스택을 넘길 수 있었습니다. Go 에서 그것은 요청 하나가 아니라 서버가 죽는 일입니다.
- **그림의 번호를 읽지 않고 찾아다녔습니다.** 도형 레코드는 작은 정수로 가득해서, 그림이 여럿인 문서에서는 전부 같은 그림이 되기 쉬웠습니다.
- `개요 7` 이 문서에 적혀 있는데도 본문으로 들어왔습니다.
- 코드 블록 확장이 선언되지 않은 채 호이스팅으로만 풀리고 있었습니다.

## 다시 생기지 않도록

**시험 파일 두 개가 형식이 아니라 읽는 쪽을 보고 만들어져 있었습니다.** 하나는 잘못된 상수를 읽는 쪽과 나눠 썼고, 하나는 그림 번호를 읽는 쪽이 찾던 자리에 두었습니다. 그래서 위의 두 잘못은 시험을 통과했습니다.

둘 다 이제 형식 문서가 적은 대로 레코드를 늘어놓습니다. **읽는 쪽을 보고 만든 시험은 읽는 쪽이 스스로와 일치한다는 것만 증명합니다** — 워드 쪽에서 결함 여섯 개를 몇 달 동안 숨긴 바로 그 잘못이고, 그것을 피하려고 쓴 시험 안에서 다시 저질렀습니다.

## 업그레이드

마이그레이션과 설정 변경은 필요하지 않습니다.

```bash
gzip -dc muni-v0.18.1.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

**v0.18.0 에서 `.hwp` 를 가져오셨다면 서식을 확인해 주세요.** 굵기와 기울임이 엉뚱하게 붙어 있을 수 있고, 그 손실은 가져오던 시점에 일어났으므로 되돌아오지 않습니다. 원본이 남아 있다면 다시 가져오면 이번에는 제대로 들어옵니다.

## 오프라인 설치

릴리스 asset 에는 `muni:v0.18.1` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.18.1.tar.gz | docker load
docker image inspect muni:v0.18.1

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- 공개 링크: `/s/{token}` — 인증 없이 열리는 유일한 화면입니다
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다
- Prometheus: `/metrics` — 관리자 인증 필요
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
