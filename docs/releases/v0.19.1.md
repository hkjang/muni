두 한글 리더를 **실제 파일**로 확인했습니다. 공개된 `.hwp` 열일곱 개와 `.hwpx` 열다섯 개 — 정부 결재 문서, 보도자료, 별지 서식 포함 — 를 내려받아 돌렸고, 그것이 찾아낸 것을 고쳤습니다. 릴리스 노트 두 개에 걸쳐 "진짜 한글 파일로 확인되지 않았다"고 적었던 그 확인입니다.

## 실제 파일이 찾아낸 것

### `.hwp` — 세 파일이 아예 읽히지 않았고, 한 원인이었습니다

표의 칸, 글상자, 각주를 뜻하는 `LIST_HEADER` 는 자기 문단들 **위**가 아니라 **앞**에, 같은 깊이로 놓입니다. 첫 낱말에 몇 문단이 따르는지 적혀 있습니다. 깊이만 보고 트리를 만들면 그 문단들은 리스트의 형제가 되어 — **모든 표의 모든 칸이 비어 보이고, 그 글은 표 옆에 매달렸습니다.** 글상자와 각주도 같은 이유로 없었습니다.

이것을 통과시킨 시험 파일은 칸의 문단을 한 단계 **깊게** 넣어 두고 있었습니다. 읽는 쪽이 바라는 대로, 형식이 쓰는 대로가 아니라. 이번 세션에서 네 번째입니다.

### `.hwp` — 태그 번호가 틀려 있었습니다

`HWPTAG_BEGIN` 부터 제대로 세면 `SHAPE_COMPONENT` 가 +76, `TABLE` 이 +77, 그림 자신의 레코드가 +85 입니다. muni 는 `TABLE` 을 +76 으로, 그림을 +91 로 알고 있었습니다. 표는 그래도 읽혔습니다 — 칸을 `LIST_HEADER` 로 찾고 `TABLE` 태그를 한 번도 보지 않았기 때문입니다. **그림은 실제 파일 어디에서도 읽히지 않았습니다.**

그리고 **실제 파일의 그림은 전부 `gso ` 로 옵니다** — 일반 그리기 개체 — 글상자도, 묶음 개체도 같습니다. `$pic` 은 한 파일에서도 보지 못했습니다.

### `.hwp` — 그림 번호의 자리가 판에 따라 다릅니다

5.0.3.x 는 그림 정보의 **맨 앞**에 번호를 적고, 5.0.2.x 는 밝기·명암·효과 **세 바이트 뒤**에 적습니다 — 홀수 자리라, 두 바이트씩 건너뛰며 찾던 예비 검색은 결코 닿을 수 없었습니다. 둘 다 시도하고, 안 되면 한 바이트씩 봅니다.

### `.hwp` — 그림을 찾고서 버렸습니다

2010년대 보고서 파일의 그림은 **전부 BMP** 였습니다. 옛 한글은 그림을 그렇게 넣었습니다. 리더가 찾아내도, 가져오기는 브라우저가 그릴 수 있는 형식만 남기므로 **세 장 전부 버려졌습니다.** 이제 BMP 는 가져올 때 PNG 로 바꿉니다.

같은 번호에 스트림이 둘인 파일도 있습니다 — `BIN0003.bmp` 옆에 `BIN0003.jpg`. 디렉터리가 먼저 내놓는 쪽을 잡았고, 그것은 우연이었습니다. 이제 브라우저가 보여 줄 수 있는 쪽을 고릅니다.

### `.hwp` — 빈 문서를 깨진 문서로 봤습니다

한글에서 빈 쪽을 저장하면 구역 정의와 단 정의만 든 문단 하나가 남습니다. 비어 있을 뿐 깨진 것이 아닌데, 거절하고 있었습니다.

### `.hwpx` — 열다섯 중 열넷이 가로 용지였습니다

세로 A4(59528 × 84188) 결재 문서에 `landscape="WIDELY"` 가 적혀 있습니다. 다른 세로 문서에는 `NARROWLY` 가 적혀 있습니다. 그 낱말이 한글에게 무슨 뜻이든 **종이가 돌아간 방향은 아닙니다.** 이제 치수만 봅니다 — 쓸 때도 한글이 세로 쪽에 쓰는 낱말을 그대로 씁니다.

### `.hwpx` — 제목이 스타일에만 있는 줄 알았습니다

실제 파일은 문단마다 `styleIDRef="0"` 을 두고 개요를 `paraPr` 의 `<hh:heading type="OUTLINE" level=…>` 에 둡니다. 이제 둘 다 봅니다.

### `.hwpx` 쓰기 — 탭이 사라졌습니다

한글은 탭을 `<hp:t>` **안에** 씁니다. muni 는 `<hp:t>` 를 닫고 탭을 두고 다시 열었고, 읽는 쪽은 그 자리에서 탭을 찾지 않았습니다. 실제 `.hwp` 열일곱 개를 `.hwpx` 로 써서 다시 읽는 왕복에서 열여섯 개가 글자까지 같았고, 하나가 이것으로 달랐습니다. 이제 열일곱 개 전부 같습니다.

### 버그가 아니었던 것

- `rhwp-english.hwp` 의 문장 열다섯 개가 제목으로 들어옵니다 — 파일이 그 문장들에 **개요 1** 을 쓰고 있습니다. 한글 사용자는 번호 매긴 문단에 개요를 흔히 쓰고, 그것이 파일이 말하는 바입니다.
- `3.hwpx`·`4.hwpx`·`5.hwpx` 는 글자가 하나도 없는 10×10 표입니다. 퍼징용 파일입니다.
- `hwpers_test4_complex_table.hwp` 는 이름과 달리 표 레코드가 없습니다.

## 남긴 것

두 검사는 저장소에 **선택적으로** 남아 있습니다. 파일은 저장소에 없고, 어느 폴더든 가리키면 같은 검사를 합니다.

```bash
MUNI_CORPUS=<dir> go test ./internal/hwp/ ./internal/hwpx/ -run 'Corpus|RealRoundTrip' -v
```

파일은 pyhwp·hwp.js·rhwp 가 공개한 것을 썼습니다. 가지고 계신 파일로 돌려 보시고 어긋나는 곳을 알려 주시면 가장 도움이 됩니다 — 이번에 열일곱 개가 찾아낸 만큼, 다음 파일이 또 무엇을 찾아낼지 모릅니다.

## 업그레이드

마이그레이션과 설정 변경은 필요하지 않습니다.

```bash
gzip -dc muni-v0.19.1.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

**v0.18.x 나 v0.19.0 에서 `.hwp` 를 가져오셨다면 다시 가져와 보세요.** 표의 칸이 비어 있거나, 그림·글상자·각주가 빠져 있거나, 서식이 엉뚱한 낱말에 붙어 있을 수 있습니다. 그 손실은 가져오던 시점에 일어났으므로 되돌아오지 않지만, 원본으로 다시 가져오면 이번에는 들어옵니다.

## 오프라인 설치

릴리스 asset 에는 `muni:v0.19.1` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.19.1.tar.gz | docker load
docker image inspect muni:v0.19.1

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- 공개 링크: `/s/{token}` — 인증 없이 열리는 유일한 화면입니다
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다
- Prometheus: `/metrics` — 관리자 인증 필요
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
