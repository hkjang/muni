제목이 100자를 넘는 문서를 내려받거나 워크스페이스를 ZIP 으로 내보낼 때 **파일 이름에 AI 프롬프트용 안내 문구와 줄바꿈이 그대로 들어가던 것**을 고쳤습니다. 화면은 바뀌지 않았고, 마이그레이션도 설정 변경도 없습니다.

## 고친 것

### 파일 이름에 붙던 「…문서 컨텍스트가 길어 일부 생략됨…」

파일 이름을 만드는 `safeFilename` 은 제목을 100룬에서 자를 때 `truncateRunes` 를 그대로 썼습니다. 그 함수는 **AI 프롬프트를 위해 쓰인 것**이라, 자르면 자른 사실을 말합니다 — 줄바꿈 하나와 `[…문서 컨텍스트가 길어 일부 생략됨…]` 한 줄을 뒤에 붙입니다. 프롬프트에서는 그 문장이 있어야 모델이 잘린 줄 압니다. 파일 이름에서는 그 문장이 곧 고장입니다.

제목은 API 에서 240자까지 받으므로 **평범한 보고서 제목이 100자를 넘습니다** — 부서·분기·용도·배포 제한을 한 줄에 적으면 그 정도가 됩니다. 그런 문서에서 두 가지가 일어났습니다.

- **내려받기 이름이 제목을 잃었습니다.** 안내 문구의 줄바꿈이 `Content-Disposition` 헤더 값으로 들어갔고, `net/http` 가 헤더 안의 줄바꿈을 공백으로 바꾸므로 파일 이름 매개변수가 따옴표 밖의 공백과 대괄호를 품은 채 나갔습니다. 헤더가 주입되지는 않았지만 매개변수는 매개변수이기를 그만두었고, 브라우저는 제목 대신 주소 끝에서 유추한 이름으로 저장했습니다.
- **ZIP 항목 이름에 그 문구가 그대로 들어갔습니다.** 아카이브 항목 이름에는 헤더 같은 정리가 없으므로, 줄바꿈과 안내 문장이 적힌 그대로 파일 이름이 되었습니다.

이제 파일 이름 전용 절단 `cutFilenameRunes` 가 **100룬에서 자르기만 하고 아무것도 붙이지 않습니다.** 자른 자리에 남는 끝 공백만 털어 냅니다 — 자르는 위치가 공백 바로 뒤일 수 있고, 공백으로 끝나는 이름은 압축 풀기 도구나 파일 시스템이 조용히 고쳐 쓰는 이름이기 때문입니다.

**바뀌지 않은 것:** 100자 이하의 제목은 한 바이트도 달라지지 않습니다. 빈 제목의 `muni-document`, 경로 구분자·제어 문자 치환, 자르는 길이 100 도 그대로입니다. `truncateRunes` 자체는 손대지 않았으므로 AI 프롬프트·첨부 이름·발송 기록 쪽은 전과 같습니다 — 그쪽에서는 안내 문구가 있어야 맞습니다. v0.43.0 이 막은 `.`·`..` 폴더 세그먼트도 그대로입니다.

`safeFilename` 을 부르는 다섯 자리가 한 번에 고쳐졌습니다 — 문서 내려받기(`txt`·`md`·`html`·`docx`·`pdf`·`hwpx`), 발표자료 내려받기, 워크스페이스 ZIP 의 파일 이름·폴더 이름·문서 항목 이름.

단위 테스트 셋(긴 제목이 이름으로만 잘리는지, 100자 이하·빈 제목·치환이 그대로인지 보는 표-주도 12건, 자른 자리가 공백일 때 이름이 공백으로 끝나지 않는지)과, 실제 라우트로 120자 제목의 문서를 만들어 **내려받기 헤더의 바이트**와 **ZIP 항목 이름**을 읽는 live 테스트 둘이 이것을 지킵니다. 단위 테스트만으로는 다섯 번째 호출자까지 닿지 않으므로 헤더와 항목 이름을 직접 읽습니다. 다섯 테스트 모두 고치기 전에 먼저 실패하는 것을 확인했습니다.

한 가지는 **일부러 고치지 않고 테스트에 적어 두었습니다.** 이 헤더는 아직 `mime.ParseMediaType` 을 통과하지 못합니다 — 경로 이스케이프가 한글 바이트를 RFC 5987 이 요구하는 퍼센트 인코딩 없이 그대로 두기 때문이고, 이는 제목 길이와 무관하게 **모든 한글 제목**에 해당합니다. 이스케이프를 넓히는 것은 그 자체로 별개의 변경이라, 다음 사람이 이번 고침의 회귀로 오해하지 않도록 기록만 남겼습니다.

## 업그레이드

마이그레이션과 설정 변경은 필요하지 않습니다. 화면은 손대지 않았고, 서버는 제목을 파일 이름으로 자르는 자리만 v0.44.0 과 다릅니다.

```bash
gzip -dc muni-v0.45.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

**이미 내려받은 파일과 ZIP 의 이름은 그대로입니다.** 이 고침은 내보내는 순간에만 적용되므로, 이름이 깨진 파일은 다시 내려받으면 됩니다.

## 오프라인 설치

릴리스 asset 에는 `muni:v0.45.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.45.0.tar.gz | docker load
docker image inspect muni:v0.45.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- 공개 링크: `/s/{token}` — 인증 없이 열리는 유일한 화면입니다
- 문서 넘기기: `/handoff?source&claim` (받는 쪽, 세션 필요, 허용 목록의 오리진만) · `/api/v1/handoff/claims/{claim}` (내주는 쪽, 인증 없이 5분짜리 단일 사용 표로만 열립니다)
- 메일 알림: 사내 SMTP 릴레이로 1분마다 배경 발송, 기본 꺼짐 · 발송 기록 `/api/v1/admin/mail/deliveries` (관리자 인증 필요)
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다
- Prometheus: `/metrics` — 관리자 인증 필요
- MCP: `/mcp`
- Momento 프록시: `/momento/*` — 방문 추적을 Momento 로 켜 둔 동안에만 답합니다
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
