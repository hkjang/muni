문서 변환(Import·Export) 전면 개편과 AI 게이트웨이 호환성 수정을 담은 릴리스입니다. 내보낸 파일이 원본 문서의 제목·목록·표·서식·이미지를 그대로 유지하고, PDF를 문서로 가져올 수 있습니다.

## 주요 변경

### PDF Import (신규)

- 외부 의존성 없는 순수 Go PDF 리더를 추가했습니다.
- 텍스트 레이어에서 제목 단계, 문단, 중첩 목록, 체크 목록, 표, 코드 블록, 이미지를 복원합니다.
- 줄바꿈된 문단을 다시 합치고(한글은 공백 없이, 영문은 하이픈 제거) 머리말·쪽번호를 걸러냅니다.
- cross-reference table이 손상된 파일도 객체 스캔으로 복구하며, Flate·LZW·ASCII85·ASCIIHex·RunLength 필터와 PNG/TIFF predictor, 객체 스트림을 지원합니다.
- 소유자 암호만 걸린 RC4·AES-128·AES-256 문서를 복호화합니다.
- ToUnicode CMap과 WinAnsi·MacRoman·Standard 인코딩, CID 폰트를 처리합니다.
- 같은 그림은 내용 해시로 한 번만 저장하고, 페이지 절반 이상에 반복되는 그림은 레터헤드·워터마크로 보고 본문에서 제외합니다.
- 텍스트 레이어가 없는 스캔본은 OCR 후 가져오라는 안내를 돌려줍니다.

### DOCX Export·Import 재작성

이전 버전의 DOCX Export는 본문을 평문 문단으로만 기록해 제목·목록·표·서식이 모두 사라졌습니다. 정식 OOXML 리더·라이터로 교체했습니다.

- Export는 `styles.xml`·`numbering.xml`·`theme1.xml`·`settings.xml`·`fontTable.xml`·`docProps`를 갖춘 완전한 패키지를 생성합니다.
- 제목 단계, 글머리·번호·체크 목록(목록마다 번호 재시작, 9단계 중첩), 표(가로·세로 병합, 열 너비, 머리글 행 반복), 굵게·기울임·밑줄·취소선·코드·형광·글자색·글꼴·크기, 하이퍼링크, 문단 정렬, 인용, 코드 블록, 구분선, 이미지가 유지됩니다.
- Import는 스타일 이름(로케일 포함), 스타일에 붙은 numbering, `w:sym` 기호, hyperlink 관계, `w14:checkbox`, 표 병합, 이미지를 해석합니다.

### Markdown·HTML·TXT 변환 개선

- Markdown은 CommonMark에 GFM 표·체크 목록·취소선을 더해 양방향으로 처리합니다. 중첩 목록, 코드 펜스, 인용, 강조, 링크, data URI 이미지가 유지됩니다.
- HTML Import가 표 병합, 문단 정렬, 인라인 스타일(색·글꼴·크기·형광), 체크 목록, 중첩 목록까지 되살립니다.
- HTML·PDF Export의 인쇄 스타일시트를 정리했습니다. 표는 페이지가 넘어가도 머리글 행이 반복되고 행 중간에서 잘리지 않습니다.
- TXT는 문단 구분과 줄바꿈을 유지합니다.
- Import한 이미지는 문서 첨부파일로 저장됩니다. 외부 URL 이미지는 서버가 대신 내려받지 않고 설명 문구를 링크로 남깁니다.

### AI 게이트웨이 호환성

OpenAI 호환 게이트웨이마다 받아들이는 요청 형태가 달라 `400` 응답으로 실패하던 문제를 수정했습니다.

- 거절 응답을 읽고 요청을 고쳐 다시 보냅니다. `max_tokens` → `max_completion_tokens` 전환, `stream_options`·`temperature` 제거, `system` → `developer`/`user` 역할 변경, 응답이 알려 준 토큰 상한 적용, 스트리밍 미지원 시 단일 응답을 SSE로 변환, base URL에 `/v1`이 빠진 경우 재시도를 처리합니다.
- 통과한 조합은 base URL·model 단위로 기억해 이후 호출은 한 번에 성공합니다.
- max token이 관리자 상한을 넘으면 거절하지 않고 상한으로 맞춥니다. 빈 system 프롬프트는 보내지 않으며, 게이트웨이가 돌려준 오류 메시지를 그대로 노출합니다.
- **서비스 관리 → 서비스 설정**의 AI 연결 테스트가 실제 호출 endpoint와 적용된 보정 내용을 함께 보여 줍니다.

### 운영·안정성

- PDF Export용 Chromium 동시 실행 수를 제한합니다(기본 2). 자리가 나기를 60초 넘게 기다리면 재시도 안내와 함께 거절합니다.
- Chromium 실행 파일을 여러 경로에서 탐색하고, 찾지 못하면 설치 안내를 담은 오류를 돌려줍니다.
- PDF 해석에 업로드 한 건당 90초 제한과 페이지·텍스트 조각 수 상한을 두었습니다.
- 업로드 파서(PDF·DOCX·Markdown·HTML)에 퍼즈 테스트 타깃을 추가했습니다.

## 업그레이드

데이터베이스 마이그레이션과 설정 변경은 필요하지 않습니다. 새 이미지로 교체하면 됩니다.

```bash
gzip -dc muni-v0.2.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

## 오프라인 설치

릴리스 asset에는 `muni:v0.2.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.2.0.tar.gz | docker load
docker image inspect muni:v0.2.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수 두 개가 추가되었습니다.

| 환경변수               | 기본값    | 설명                                         |
| ---------------------- | --------- | -------------------------------------------- |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로   |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)     |

`ENCRYPTION_KEY`는 온라인 준비 환경에서 `openssl rand -base64 32`로 생성해 안전하게 전달하십시오. Keycloak, AI, 승인, 공유, 보안, Export 등 나머지 설정은 로그인 후 **서비스 관리 → 서비스 설정**에서 관리합니다.

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- OpenAPI: `/api/openapi.yaml`
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
