`.hwp` 가져오기에 남아 있던 빈틈 셋 — 줄간격, 하이퍼링크, 용지 방향 — 을 닫았고, 하이퍼링크는 `.hwpx` 로 들어오고 나가기도 합니다. v0.20.0 이 남긴 목록에서 사용자 결정이 필요 없는 항목들입니다.

## 추가

### `.hwp` — 줄간격

문단 모양은 줄간격을 **두 번** 적습니다. 24바이트째에 옛 판을 위해, 50바이트째에 새 판을 위해 — 실제 파일은 두 자리에 같은 수를 둡니다. 종류가 "글자에 따라"(백분율)일 때만 글꼴의 배수이고, 고정값은 HWPUNIT 이라 배수가 아닙니다. 종류는 세 번째 속성 낱말에 있습니다. 보도자료 파일 하나에서 120·130·140·160·170% 가 들어옵니다.

### `.hwp` — 하이퍼링크

링크는 **필드**입니다. 문단 글자 속의 필드 시작 표시(3)와 끝 표시(4) 사이가 링크의 글자이고, 어느 필드인지는 문단에 딸린 필드 제어들이 같은 차례로 말합니다. 주소는 `%hlk` 제어의 명령 문자열 — id, 속성 낱말, 표시 바이트 하나 뒤의 길이 붙은 문자열 — 앞부분이며, 한글은 `http\://` 처럼 콜론을 벗어나게 적습니다. 다른 종류의 필드(누름틀, 날짜)는 자리만 세고 링크로 만들지 않습니다.

### `.hwp` — 용지 방향

구역 정의 제어 아래의 용지 정의에서 너비와 높이를 읽어, 첫 구역이 가로면 문서를 가로로 가져옵니다 — `.hwpx` 와 Word 에서 하던 것과 같습니다.

### `.hwpx` — 하이퍼링크, 양방향

읽을 때는 `<hp:fieldBegin type="HYPERLINK">` 의 `Command` 매개변수에서 주소를 꺼내 끝 표시까지의 글자에 붙이고, 쓸 때는 링크 글자 앞뒤에 같은 필드를 씁니다. 모양은 한글이 쓰는 것을 다른 구현(rhwp)이 쓴 파일로 확인했고, muni 가 쓴 파일을 rhwp 가 읽으면 원본 `.hwp` 에서와 같은 링크 하나를 냅니다.

## 확인

실제 파일 열일곱 개의 왕복과 열다섯 개의 읽기, rhwp 의 파싱과 글자 대조가 v0.20.0 과 같이 통과합니다.

## 업그레이드

마이그레이션과 설정 변경은 필요하지 않습니다.

```bash
gzip -dc muni-v0.21.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

**`.hwp` 를 가져오셨다면 다시 가져와 보세요.** 줄간격·하이퍼링크·용지 방향은 이번에 처음 들어옵니다. `.hwpx` 의 하이퍼링크도 같습니다.

## 오프라인 설치

릴리스 asset 에는 `muni:v0.21.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.21.0.tar.gz | docker load
docker image inspect muni:v0.21.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- 공개 링크: `/s/{token}` — 인증 없이 열리는 유일한 화면입니다
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다
- Prometheus: `/metrics` — 관리자 인증 필요
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
