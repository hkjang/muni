v0.2.0에서 컨테이너 안의 PDF 내보내기가 실패하던 문제를 고친 패치 릴리스입니다. 편집기에서 문장을 선택해 AI로 고쳐 쓰는 기능도 함께 들어갔습니다.

## 수정

### PDF 내보내기 실패 (v0.2.0 영향)

`muni:v0.2.0` 이미지에서 PDF 내보내기가 항상 `EXPORT_FAILED`로 실패했습니다.

서비스는 홈 디렉터리가 없는 비 root 계정으로 동작하는데, Chromium의 크래시 처리기가 `HOME` 아래에 데이터베이스를 만들지 못하면 브라우저 자체를 중단시킵니다.

```
chrome_crashpad_handler: --database is required
```

렌더링마다 만드는 임시 디렉터리를 `HOME`과 `XDG_CONFIG_HOME`, `XDG_CACHE_HOME`으로 지정해 해결했습니다. `--disable-crash-reporter`나 `--crash-dumps-dir`로는 해결되지 않습니다.

DOCX·HTML·Markdown·TXT 내보내기와 모든 가져오기는 v0.2.0에서도 정상 동작했습니다. 이 릴리스는 실제 릴리스 이미지를 PostgreSQL과 함께 기동해 다섯 가지 형식의 내보내기와 다시 가져오기까지 확인했습니다.

## 추가

### 선택 영역 AI 메뉴

편집기에서 문장을 드래그해 선택하면 선택 영역 위에 AI 메뉴가 나타납니다.

- 다듬기, 짧게, 자세히, 맞춤법, 격식체, 요약, 목록으로, 영어로
- 직접 지시 입력

결과는 문서에 곧바로 반영되지 않습니다. 스트리밍 미리보기로 먼저 보여 주고 **적용**을 눌러야 선택 영역을 대체하므로, AI가 고친 내용은 사람이 받아들이기 전까지 제안 상태로 남습니다. 한 줄 답변은 문장 안에 그대로 들어가고, 여러 문단은 문단으로, 전부 목록 형태면 실제 불릿 목록으로 변환됩니다.

편집 모드에서 편집 권한이 있고 관리자가 AI를 켜 둔 경우에만 표시됩니다.

## 개발 편의

- GitHub Actions 워크플로의 액션을 Node 24 릴리스로 올려 실행마다 뜨던 deprecation 경고를 없앴습니다.
- `webui/dist`에는 placeholder `index.html`만 커밋되어야 하는데 프런트엔드를 빌드하면 덮어써집니다. CI와 `make test`가 이를 검사하고, `make hooks`로 같은 검사를 pre-commit 훅에 설치할 수 있습니다.
- 프런트엔드 단위 테스트가 CI에서 실행됩니다. `vitest`가 Playwright 스펙을 함께 수집하던 문제도 정리했습니다.

## 업그레이드

데이터베이스 마이그레이션과 설정 변경은 필요하지 않습니다. 새 이미지로 교체하면 됩니다.

```bash
gzip -dc muni-v0.2.1.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

## 오프라인 설치

릴리스 asset에는 `muni:v0.2.1` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.2.1.tar.gz | docker load
docker image inspect muni:v0.2.1

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- OpenAPI: `/api/openapi.yaml`
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.

