계정 없는 사람에게 문서를 보낼 수 있게 되었습니다. AI에게 "더 짧게"라고 말하면 통합니다. 첨부파일과 서식을 정리할 수 있게 되었습니다. 그리고 권한이 없어 거부된 요청이 지금까지 **성공했다고 답하고 있었습니다.**

## 추가

### 공개 링크

문서 공개 범위에 `LINK`라는 값이 첫 마이그레이션부터 있었고, 관리자 설정의 「공개 링크 공유 허용」이 그것을 통제하는 것처럼 보였습니다. 그런데 접근 판정에 `LINK`는 존재하지 않았고 링크로 문서를 여는 경로도 없었습니다. **설정해도 아무 일이 일어나지 않았습니다.** 빠져 있던 것이 이 기능입니다.

문서 소유자가 `공유 → 공개 링크`에서 계정 없는 사람도 읽을 수 있는 주소를 만듭니다. 비밀번호, 만료 시각, 열람 횟수를 걸 수 있습니다.

만나본 적 없는 사람을 상대하는 코드라 규칙을 좁게 잡았습니다.

- **읽기 전용입니다.** 익명 편집자가 만든 변경은 누구에게 귀속시킬 방법이 없습니다.
- **주소는 저장하지 않습니다.** 앞부분으로 행을 찾고 해시로 나머지를 상수 시간에 확인합니다. 데이터베이스 사본은 동작하는 링크 목록이 아닙니다. 화면에도 만든 직후 한 번만 보이고, 목록에는 앞부분만 나옵니다.
- **틀린 주소와 없는 주소의 답이 같습니다.** 앞부분이 맞았다는 사실조차 알려주지 않습니다.
- **관리자 설정이 양방향으로 통제합니다.** 끄면 새로 만들 수 없고 **이미 있는 링크도 열리지 않습니다.** 새 링크만 막는 스위치는 문서가 잘못 나갔을 때 관리자가 찾는 스위치가 아닙니다.
- **열람 횟수는 세는 문장에서 막습니다.** 마지막 한 번을 두 사람이 동시에 열어도 한 명만 들어갑니다.
- 해지해도 행은 남습니다. 그 문서가 밖으로 나갔고 몇 번 열렸는지가 그 행의 내용입니다. 열람은 감사 로그에 `VIEW_DOCUMENT_LINK`로 남고, 로그인한 사람이 없으므로 행위자는 비어 있고 접속 주소가 기록됩니다.
- 나가는 것은 **문서뿐입니다.** 워크스페이스 이름도, 소유자도, 다른 문서도 이 경로로 나가지 않습니다.

`서비스 관리 → 문서 관리 → 권한 보기`가 살아 있는 링크를 함께 보여줍니다. 빼놓으면 "누가 열 수 있나"라는 질문에 이름을 아는 사람만 답하는 화면이 됩니다.

### AI가 앞의 답을 기억합니다

에이전트 패널이 질문 사이에 아무것도 기억하지 않았습니다. 요청마다 메시지 하나만 보내서 **"더 짧게"에는 짧게 만들 대상이 없었고**, 이어지는 질문마다 전체를 다시 말해야 했습니다. 서버는 처음부터 메시지 목록을 받고 있었고, 그것을 보내는 쪽이 없었을 뿐입니다.

대화가 화면에 쌓이고, 답마다 도구 사용 내역과 생각한 과정이 접힌 채 함께 남습니다. Enter로 보내고 Shift+Enter로 줄을 바꿉니다.

**답이 오지 않은 질문은 기록에서 빠집니다.** 오지 않은 답을 있었던 것처럼 남기지 않고, 실패한 턴을 다음 질문의 문맥으로 보내지도 않습니다. 질문은 입력란으로 돌아가 다시 보낼 수 있습니다.

### 첨부파일 정리

파일을 올릴 수는 있는데 지울 방법이 없었습니다. 삭제 엔드포인트는 완성돼 있었고 아무도 부르지 않았습니다. 잘못 끌어다 놓은 이미지가 문서가 살아 있는 동안 남았고, **거기 있다는 사실조차 어느 화면도 말해주지 않았습니다.**

편집기 사이드바에 「첨부」 탭이 생겼습니다. 다만 이 목록의 쓸모는 "무엇이 붙어 있나"가 아니라 **"무엇이 아직 쓰이고 있나"** 입니다. 본문에서 지운 파일은 가리키는 것 없이 용량만 차지하고, 정리해야 할 것이 바로 그것입니다. 목록이 그 둘을 구분해 보여주고, 아직 쓰이는 파일을 지우려 하면 **그 자리가 깨진 이미지로 남는다고 먼저 알려줍니다.**

### 서식 정리

서식은 만들 수만 있었습니다. 이름 변경도 삭제도 서버에는 있었고 아무도 부르지 않았습니다. 워크스페이스는 누군가 저장한 모든 서식을 오타까지 포함해서, 문서를 시작할 때 모두가 보는 드롭다운에 영원히 들고 있었습니다.

그 목록을 읽는 자리가 어수선함을 알아채는 자리이므로 정리하는 버튼도 거기에 뒀습니다. 서식을 지워도 **그것으로 만든 문서는 그대로 남는다고** 확인 화면이 말해 줍니다.

## 수정

### 권한이 없어 거부된 요청이 성공했다고 답하고 있었습니다

문서 권한 확인에 실패하면 핸들러가 아무것도 쓰지 않고 반환했고, 아무것도 쓰지 않은 핸들러는 **빈 본문의 `200 OK`** 를 보냅니다. 동작 자체는 정확히 막혔지만 — 문서는 바뀌지 않았고 공유는 저장되지 않았습니다 — **모든 클라이언트가 성공했다고 들었습니다.** 권한 없는 편집자는 저장됐다는 확인을 받고 계속 입력하고, 일어나지 않은 공유가 공유된 것처럼 보였습니다.

핸들러 **21곳**이 그랬습니다. 편집·공유·댓글·태그·이동·첨부·결재·발표자료·AI 패치 전부입니다.

권한 없음은 403, 없는 문서는 404, 그 밖은 500으로 나갑니다. 없는 문서에 403을 답하는 것은 그것이 존재한다고 알려주는 것이므로 구분합니다. 실제로 여덟 개 엔드포인트를 권한 없는 계정으로 호출해 보고 **답이 4xx인지, 본문에 이유가 들어 있는지, 그리고 아무것도 바뀌지 않았는지**까지 확인하는 테스트를 남겼습니다.

## 업그레이드

마이그레이션이 하나 있습니다(`013`, 공개 링크 테이블). 기동할 때 자동으로 적용되고 설정 변경은 필요하지 않습니다.

공개 링크는 관리자 설정의 「공개 링크 공유 허용」이 켜져 있어야 동작하며, **기본값은 꺼짐입니다.** 그대로 두시면 이 릴리스로 밖에 나가는 경로는 생기지 않습니다.

```bash
gzip -dc muni-v0.14.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

## 오프라인 설치

릴리스 asset에는 `muni:v0.14.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.14.0.tar.gz | docker load
docker image inspect muni:v0.14.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- 공개 링크: `/s/{token}` — 인증 없이 열리는 유일한 화면입니다
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다
- Prometheus: `/metrics` — 관리자 인증 필요
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.

## 릴리스 파일 검증

- 파일: `muni-v0.14.0.tar.gz`
- 크기: 릴리스 게시 후 기재
- SHA-256: 릴리스 게시 후 기재
- 내부 이미지 태그: `muni:v0.14.0`

```bash
sha256sum muni-v0.14.0.tar.gz
```
