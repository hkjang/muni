편집 화면을 문서 편집기답게 끌어올린 릴리스입니다. 구글 독스를 쓰던 사람이 찾다가 없어서 아쉬웠던 기능들을 채웠습니다.

## 추가

### 문서 개요

편집 화면 왼쪽에 제목으로 만든 목차가 붙습니다. 긴 문서에서 원하는 곳으로 가는 가장 빠른 방법이고, 지금 보고 있는 절이 표시됩니다.

들여쓰기는 `제목 1`이 아니라 **문서에 실제로 쓰인 가장 얕은 단계**를 기준으로 잡습니다. `제목 2`와 `제목 3`으로만 쓴 문서가 오른쪽으로 밀려 그려지지 않습니다. 단계를 건너뛰어도 한 칸만 들어갑니다.

`Ctrl+\`로 열고 닫습니다.

### 찾기와 바꾸기

`Ctrl+F`로 찾고, `Ctrl+H`로 바꿉니다.

브라우저 찾기는 패널 안에서 스크롤되는 문서를 제대로 보지 못하고, 바꿀 수도 없습니다.

- 일치하는 곳이 모두 표시되고 **지금 보고 있는 것**은 다르게 강조됩니다.
- `Enter`로 다음, `Shift+Enter`로 이전으로 이동합니다.
- 대문자 구분, 단어 단위 옵션이 있습니다.
- 하나씩 바꾸거나 모두 바꿀 수 있습니다.

검색은 문서를 한 줄 문자열로 펼쳐서 수행합니다. **한 단어만 굵게 처리해도** 문장이 여러 조각으로 나뉘는데, 그런 문구를 찾으려면 이 방법뿐입니다. 문단 경계를 넘는 일치는 만들지 않습니다.

단어 단위 옵션은 한국어를 고려합니다. `회의`를 단어 단위로 찾으면 `회의록` 안쪽은 걸리지 않습니다.

### 단어 수와 글자 수

문서 아래에 단어 수, 글자 수, 공백 제외 글자 수, 대략적인 읽는 시간이 표시됩니다.

**무언가를 선택하면 선택 영역의 수치**로 바뀝니다. 분량 제한이 있는 문서에서 한 절을 줄일 때 쓰라고 만든 것입니다.

### 표 편집

표 안에 커서가 있으면 표 도구가 나타납니다. 행·열 추가와 삭제, 헤더 행 전환, 셀 병합과 분할, 표 삭제.

표를 넣을 수는 있는데 행을 추가할 수 없는 건 표라고 하기 어려웠습니다.

### 단축키 안내

`Ctrl+/`로 단축키 목록을 봅니다. 문서·서식·문단 단축키와, `# ` `- ` `1. ` 처럼 **입력하면 서식으로 바뀌는** 표기도 함께 정리돼 있습니다.

### 줄 간격과 서식 지우기

도구 모음에 줄 간격(1~2.5)과 서식 지우기가 생겼습니다. 보고서 양식이 요구하는 160% 줄 간격을 빈 문단으로 흉내 내지 않아도 됩니다.

### 확대·축소

문서 아래에서 50~200%로 조절합니다. 글을 다시 흘리지 않고 **종이를 확대하듯** 배율만 바꾸므로, 줄이 바뀌는 위치가 그대로 유지됩니다. 설정은 브라우저에 기억됩니다.

### 이름 있는 버전

버전에 이름을 붙일 수 있습니다. `부서 검토본`, `최종 제출` 처럼요. 이름이 있는 버전은 목록에서 구분되어 보입니다.

시각만 나열된 목록은 사실상 쓸 수 없는 기록이었습니다.

## 개선

### 댓글이 편집을 견딥니다

댓글을 위치로만 저장하고 있어서, **위쪽에 문단 하나만 추가해도** 댓글이 엉뚱한 줄을 가리켰습니다.

이제 댓글이 남겨진 블록의 안정적인 ID와 선택했던 문장을 함께 기록합니다. 문서가 편집돼도 댓글은 원래 가리키던 곳을 계속 가리키고, 댓글의 인용 부분을 누르면 본문의 해당 위치로 이동합니다. 블록이 사라졌으면 문서 전체에서 그 문장을 찾고, 문장까지 바뀌었으면 그 블록으로 데려갑니다.

### 인쇄

`Ctrl+P`가 편집기 화면이 아니라 **문서를 인쇄**합니다.

편집 영역은 스크롤되는 상자 안에 있어서, 그대로 인쇄하면 화면에 보이던 만큼만 나왔습니다. 이제 인쇄할 때는 문서가 자연스럽게 이어지고 주변 UI는 빠집니다. 제목이 페이지 마지막 줄에 홀로 남지 않고, 표·이미지·인용은 페이지 중간에서 잘리지 않습니다.

## 업그레이드

데이터베이스 마이그레이션과 설정 변경은 필요하지 않습니다. 새 이미지로 교체하면 됩니다.

```bash
gzip -dc muni-v0.5.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

이전에 작성된 댓글은 위치 정보만 가지고 있습니다. 저장했던 문장으로 본문에서 다시 찾으므로 대부분 정상 동작하며, 새로 다는 댓글부터 블록 ID가 함께 기록됩니다.

## 오프라인 설치

릴리스 asset에는 `muni:v0.5.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.5.0.tar.gz | docker load
docker image inspect muni:v0.5.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |
