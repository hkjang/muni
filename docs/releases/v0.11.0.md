문서를 옮기고, 복제하고, 여러 건을 한 번에 다루고, 워크스페이스를 통째로 내보낼 수 있게 되었습니다. 검색에 필터가 생겼고, 공개 API 문서가 실제와 일치하게 되었습니다.

## 추가

### 문서 이동과 폴더 관리

폴더는 **문서를 만드는 순간에만** 고를 수 있었습니다. 나중에 옮길 방법이 없었고, 폴더 자체도 만들기와 목록뿐이었습니다 — 이름 변경도, 삭제도, 다른 폴더 안으로 넣기도 없었습니다. 잘못 넣은 문서는 거기 그대로 있었습니다.

이제 문서를 다른 폴더나 워크스페이스로 옮기고, 폴더를 바꾸고 지울 수 있습니다.

- 워크스페이스를 옮기면 문서를 볼 수 있는 사람이 달라지므로, 편집 방을 닫아 열어 두고 있던 사람이 새 권한으로 다시 연결됩니다.
- 폴더를 **자기 하위 폴더 안으로** 옮기면 그 가지가 트리에서 떨어져 나가 아무도 찾을 수 없게 됩니다. 조상 관계를 따라 확인하고 거부합니다.
- 폴더를 지워도 **안에 있던 문서와 하위 폴더는 지워지지 않고 상위로 올라갑니다.** 폴더를 정리하는 사람이 문서를 없애달라고 한 것은 아니고, 폴더와 함께 사라진 문서는 휴지통에서 찾아 헤매야 합니다.

폴더 선택 목록은 이름이 아니라 경로를 보여줍니다. `2025 / 상반기`와 `2026 / 상반기`는 이름만으로 구분되지 않습니다.

### 여러 문서를 한 번에

한 달치 회의록 정리, 감사 대비 태그 달기, 끝난 프로젝트 치우기 — 전부 한 건씩이었고, 그래서 폴더와 태그가 정돈된 워크스페이스가 없었습니다.

워크스페이스에서 문서를 선택해 폴더로 옮기고, 태그를 달고, 휴지통으로 보낼 수 있습니다.

일괄 작업은 **문서마다 결과를 돌려줍니다.** 마흔한 번째가 승인 대기 중이라고 마흔 건을 거부하는 것은 누구에게도 도움이 되지 않고, 조용히 건너뛰는 것은 더 나쁩니다. 건너뛴 문서는 이유와 함께 돌아오고, 화면이 그렇게 말합니다.

문서마다 권한을 따로 확인합니다. 휴지통으로 보내려면 소유자여야 하고, 옮기거나 태그를 달려면 편집 권한이 필요하며, 승인 대기 중인 문서는 일괄 작업으로도 삭제되지 않습니다. 일괄 이동은 문서가 속한 워크스페이스 안에서만 일어납니다 — 워크스페이스를 넘기면 볼 수 있는 사람이 바뀌는데, 그건 드롭다운 하나로 마흔 건에 적용할 일이 아닙니다.

### 문서 복제

지난달 보고서에서 이번 달 것을 시작하는 게 가장 흔한 경우인데, 방법이 둘뿐이었습니다. 서식으로 저장하거나(한 사람이 한 번 필요한 일에 워크스페이스 전체를 두고 내리는 결정입니다), 전체 선택해서 새 문서에 붙여넣거나(태그와 폴더를 잃습니다).

복사본은 내용·폴더·**태그**를 가져갑니다. 대외비 보고서의 사본도 대외비이고, 손으로 다시 태그를 다는 것은 잊어버리는 경로입니다.

댓글·제안·결재·버전 기록은 원본에 남습니다. 그것은 **그 문서에 일어난 일의 기록**이고, 사본에는 아직 아무 일도 일어나지 않았습니다.

### 워크스페이스 통째로 내보내기

문서를 한 번에 하나씩만 꺼낼 수 있었습니다. 부서 이관, 감사 대응, 폐기 전 보관 — 전부 문서마다 클릭해야 했고, 그래서 아무도 실제로 하지 않던 일들입니다.

관리자는 워크스페이스 전체를 압축 파일 하나로 내려받을 수 있습니다. **폴더 구조 그대로**, 무엇이 들어 있는지 적은 목록과 함께.

- 연결로 바로 씁니다. 큰 워크스페이스가 메모리나 디스크에 올라갈 일이 없습니다.
- 같은 제목의 문서 두 건은 **두 파일**이 됩니다. 하나로 합쳐지면 내보내기가 조용히 문서를 잃습니다.
- 휴지통을 포함할 경우 별도 디렉터리로 들어갑니다. 압축을 풀어도 지운 문서가 살아 있는 문서 사이에 섞이지 않습니다.

Markdown·HTML·텍스트를 지원합니다. 문서 천 건을 Chromium에 통과시키는 것은 내려받기가 아니고, DOCX는 압축하는 동안 렌더링된 파일을 전부 들고 있어야 합니다.

### 검색 필터

검색창 하나가 전부였습니다. 워크스페이스·작성자·태그·기간으로 거를 수 있습니다. 태그는 직전 릴리스에서 추가되어 검색어로는 걸렸지만 **필터로는 쓸 수 없었습니다.**

**키워드 없이 필터만으로도** 검색됩니다 — "지난달에 내가 여기 쓴 것 전부"에는 검색어가 없습니다. 조건은 주소에 담기므로 공유하거나 북마크할 수 있습니다.

## 수정

### 공개 API 문서가 실제의 3분의 1만 기술하고 있었습니다

muni는 라우트 **112개**를 서비스하면서 그중 **45개**만 기술한 문서를 공개하고 있었습니다. 연동을 만들려는 사람은 3분의 1만 맞는 지도를 읽고 있었던 셈입니다. 손으로 관리되는 문서였고 아무도 확인하지 않았기 때문입니다.

이제 라우트를 등록하면서 기록하고, **테스트가 양방향으로 대조**합니다. 기술되지 않은 라우트도 실패하고, 서비스하지 않는데 기술된 것도 실패합니다. 경로 매개변수 이름은 정규화해서 비교합니다 — 라우트가 `{id}`라 부르는 것을 문서가 `{documentId}`라 부르는 것은 같은 엔드포인트이고, 문자열로 비교하면 전부 누락으로 잡힙니다.

실제로 빠져 있던 44개를 채웠고, 이번 릴리스에서 추가한 엔드포인트는 **가드가 먼저 잡아냈습니다.**

### 로그인 시도 제한

로그인 실패는 200밀리초 지연이 전부였습니다. 그것은 한 번에 하나를 늦출 뿐, 동시에 보낸 백 개는 늦추지 못합니다 — 지연이 병렬로 소화되기 때문입니다.

이제 실패 횟수를 셉니다. **주소와 계정을 묶어서** 세는데, 이건 의도한 것입니다.

- 계정만 세면 누구나 남의 아이디를 찍어서 그 사람을 잠글 수 있습니다.
- 주소만 세면 한 사람의 실수로 같은 게이트웨이 뒤의 사무실 전체가 막힙니다.

로그인에 성공하면 횟수는 지워집니다. 기록은 메모리에만 두어 재시작보다 오래 남지 않습니다.

## 업그레이드

데이터베이스 마이그레이션과 설정 변경은 필요하지 않습니다.

```bash
gzip -dc muni-v0.11.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

## 오프라인 설치

릴리스 asset에는 `muni:v0.11.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.11.0.tar.gz | docker load
docker image inspect muni:v0.11.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다

- 지원 DB: PostgreSQL 15 이상
