AI 기능 사용 중 보고된 문제 두 건을 고치고, 빠른 이동 창을 추가한 릴리스입니다.

## 수정

### 문서를 열고 AI를 실행하면 400으로 실패하던 문제

문서를 연 상태에서 오른쪽 AI 패널의 요약·검토 같은 버튼을 누르면 게이트웨이가 `400`을 돌려주며 실패했습니다. 오류 메시지는 system 메시지를 가리켰습니다.

muni는 모델에 줄 지시가 여러 개입니다 — 관리자 프롬프트, 질문 대상 문서, 도구 사용법. 이를 **각각 별개의 system 메시지로** 보내고 있었고(에이전트 경로는 세 개), system 메시지를 하나만 허용하거나 맨 앞에만 허용하는 게이트웨이는 이런 요청을 그대로 거절합니다.

이제 모든 지시를 **하나의 system 메시지로 합쳐** 맨 앞에 보냅니다. 어느 게이트웨이에서도 유효한 형태입니다.

게이트웨이가 system 메시지에 대해 무언가를 말하며 거절하면 한 번은 system 없이 재시도합니다. 거절 문구가 `must be first`, `only one allowed`, `not supported` 등 제각각이라 정확히 구분하기 어렵고, 지시가 user 턴으로 전달되는 편이 요청 실패보다 훨씬 낫기 때문입니다.

### 모델의 추론이 결과에 섞여 나오던 문제

추론을 켜지 않아도 일부 모델(특히 Qwen 계열)은 생각을 먼저 내보내고 **여는 태그 없이 닫는 `</think>`만** 붙입니다. 그 앞부분이 답변으로 취급되어, 드래그해서 쓰는 선택 영역 AI 기능에서는 **모델의 추론이 문서에 그대로 적용**되었습니다.

이제 추론 구간을 양쪽에서 제거합니다.

- 서버: 변경 제안 파서가 JSON을 찾는 자리에 중괄호 섞인 추론을 받지 않도록
- 스트리밍: 미리보기에도 추론이 보이지 않도록

`<think>…</think>` 쌍, 닫는 태그만 있는 경우, 아직 닫히지 않은 경우를 모두 처리하며 `<thinking>`·`<reasoning>` 표기도 함께 걷어냅니다. 추론이 끝나지 않은 동안에는 **생각하는 중…** 으로 표시합니다.

## 추가

### 빠른 이동

`Ctrl+K`(macOS는 `⌘K`), 또는 글을 쓰고 있지 않을 때 `/`를 누르면 빠른 이동 창이 열립니다.

- 최근 문서·워크스페이스·주요 화면이 입력 전에 바로 보입니다.
- 두 글자 이상 입력하면 서버 검색으로 본문까지 찾습니다.
- 방향키와 Enter로 이동하고, `Esc`로 닫습니다.

제목이 정확히 맞는 항목, 제목이 그 말로 시작하는 항목, 단어 첫머리가 맞는 항목 순으로 위에 옵니다. `추계`처럼 글자만 순서대로 친 경우도 `추진 계획`을 찾습니다. 상단 검색창을 클릭해도 같은 창이 열립니다.

## 업그레이드

데이터베이스 마이그레이션과 설정 변경은 필요하지 않습니다. 새 이미지로 교체하면 됩니다.

```bash
gzip -dc muni-v0.3.1.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

## 오프라인 설치

릴리스 asset에는 `muni:v0.3.1` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.3.1.tar.gz | docker load
docker image inspect muni:v0.3.1

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- OpenAPI: `/api/openapi.yaml`
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
