`muni`의 첫 공개 릴리스입니다. 폐쇄망·온프레미스 환경에서 브라우저 기반 문서 작성과 실시간 협업, 문서 업무 흐름, AI 기능을 하나의 서비스 이미지로 운영할 수 있습니다.

## 주요 기능

- React + Material UI + Tiptap 기반의 가독성 높은 문서 편집 UI
- Yjs CRDT와 WebSocket을 이용한 다중 사용자 실시간 공동편집 및 오프라인 재동기화
- 개인·팀 Workspace, 중첩 Folder, 최근 문서, 공유 문서, 즐겨찾기, 휴지통
- 문서 Revision, 복원, 댓글·답글, 제안 수락·반려, OWNER/EDITOR/COMMENTER/VIEWER ACL
- 관리자 설정에 따른 선택적 검토·승인·반려 프로세스
- Keycloak OIDC 자동 연동과 로컬 bootstrap 관리자
- OpenAI-compatible SSE 스트리밍 AI와 최대 262,144 token 설정
- 사용자별 envelope key 회전·폐기 및 역할별 변경 가능한 키 권한 정책
- 개인 API key, REST OpenAPI 3.1, MCP Streamable HTTP
- PostgreSQL FTS 검색, 감사 로그, 첨부파일
- DOCX·Markdown·TXT·HTML Import
- DOCX·PDF·HTML·Markdown·TXT Export

## 오프라인 설치

릴리스 asset에는 `muni:v0.1.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.1.0.tar.gz | docker load
docker image inspect muni:v0.1.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 읽는 런타임 환경변수는 다음 네 개뿐입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

`ENCRYPTION_KEY`는 온라인 준비 환경에서 `openssl rand -base64 32`로 생성해 안전하게 전달하십시오. Keycloak, AI, 승인, 공유, 보안, Export 등 나머지 설정은 로그인 후 **서비스 관리 → 서비스 설정**에서 관리합니다.

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- OpenAPI: `/api/openapi.yaml`
- MCP: `/mcp`
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
